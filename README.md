
# 🕳️ 是男人就下一百层

在手机浏览器中运行的"是男人就下一百层"像素风格小游戏，纯 HTML5 Canvas 单文件实现。

## 🎮 玩法

- **左右半屏触控** 控制角色移动
- 踩住平台不断下降，挑战最高层数
- 四种平台：🟢普通 🔵移动 🟠断裂 🔴尖刺
- 支持键盘（A/D / 方向键）和鼠标

## ✨ 特性

- 像素风角色 Sprite（idle / walk / fall / land）
- 四类平台纹理（草地 / 传送带 / 裂纹 / 尖刺）
- 3 层视差背景（星空 / 都市 / 砖墙）
- 350 粒子池：着地灰尘、断裂碎片、死亡爆炸
- Web Audio 合成音效 + 振动反馈
- 屏幕特效：暗角、红光、闪光、抖动
- 三难度选择（简单 / 普通 / 困难）
- 里程碑系统、统计数据、自动性能降质

## 🚀 使用方法

直接在手机或 PC 浏览器中打开 `game.html` 即可开始游戏。
